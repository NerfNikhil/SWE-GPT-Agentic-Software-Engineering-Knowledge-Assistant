# SWE-GPT-Agentic-Software-Engineering-Knowledge-Assistant
Developed SWE-GPT, an Agentic RAG-based Software Engineering Knowledge Assistant using LangGraph, Qdrant, FastAPI, and Hugging Face models. Implemented Corrective-RAG, query rewriting, retrieval grading, and adaptive routing to improve answer relevance and reliability. Evaluated system performance using RAGAS metrics.
